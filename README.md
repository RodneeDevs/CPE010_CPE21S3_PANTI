📌 Course Overview

Course Code: CPE 010

Course Title: Data Structures and Algorithms

Credits: 2 Units (2 units laboratory | 6 Hours Laboratory per week)

Prerequisites: CPE009A (Object-Oriented Programming 1), MATH006 (Discrete Math)

Co-requisites: None

Programming Language: C++

Course Description:

This course focuses on solving computational problems that manipulate collected data, studying a core set of data abstractions, data structures, and algorithms that provide a foundation for writing efficient programs. Course content includes theoretical topics in algorithmic efficiency and complexity, abstract data types (graphs, networks, trees, heaps, stacks, queues), searching techniques (hashing, binary search), and sorting algorithms. Students design and implement data structures and algorithms to solve engineering-related problems using C++.

📚 Course Outline & Topic Learning Outcomes

🔴 PRELIM PERIOD

Module I: Course Introduction

Topics: TIP Vision and Mission; Graduate Attributes / Institutional Learning Outcomes; Program Educational Objectives (PEOs) & Student Outcomes (SOs); Syllabus Overview; Laboratory Software & Tools Setup.

Topic Learning Outcomes:

Understand the course objectives, requirements, and policy on Artificial Intelligence (AI) tool usage.

Configure the C++ development environment and laboratory software tools required for the course.

Module II: Introduction to Data Structures and Algorithm Analysis

Topics: C++ Programming Review, Abstract Data Types (ADTs), Space and Time Complexity, Algorithm Analysis Techniques.

Topic Learning Outcomes:

Differentiate between primitive data types and Abstract Data Types (ADTs).

Review key C++ concepts including pointers, references, and memory allocation.

Explain the fundamentals of space and time complexity in computing.

Perform basic theoretical algorithm analysis using Big-O notation principles.

Module III: Arrays and Linked Lists

Topics: Dynamic Memory Allocation; Singly, Doubly, and Circular Linked Lists.

Topic Learning Outcomes:

Manage memory dynamically in C++ using new and delete operators.

Implement Singly, Doubly, and Circular Linked Lists from scratch.

Perform fundamental operations (insertion, deletion, traversal, searching) on various linked list structures.

Evaluate the trade-offs between static arrays, dynamic arrays, and linked lists in terms of memory and performance.

Module IV: Stacks

Topics: Stack ADT, Stack implementation using Arrays, Stack implementation using Linked Lists, C++ Implementation, Problem Solving.

Topic Learning Outcomes:

Define the Last-In, First-Out (LIFO) property of the Stack ADT.

Implement stack operations (push, pop, peek, isEmpty) using both contiguous (array) and linked representations in C++.

Apply stack data structures to solve classical engineering and computational problems (e.g., expression evaluation, backtracking, function call stacks).

🟡 MIDTERM PERIOD

Module V: Queues

Topics: Queue ADT, Queues using Arrays, Queues using Linked Lists, Circular Queues, C++ Implementation, Problem Solving.

Topic Learning Outcomes:

Define the First-In, First-Out (FIFO) property of the Queue ADT.

Implement standard and circular queues using array-based and linked-list-based structures in C++.

Apply queue data structures to practical problem-solving scenarios (e.g., process scheduling, buffer management).

Module VI: Searching Techniques

Topics: Linear Search, Binary Search, Hashing (Hash Functions, Collision Resolution Techniques).

Topic Learning Outcomes:

Implement and compare sequential (linear) search and binary search algorithms.

Explain the principles of hashing, hash functions, and collision resolution strategies (e.g., chaining, open addressing).

Select appropriate searching techniques based on dataset structure and performance requisites.

Module VII: Sorting Algorithms

Topics: Basic Sorting Algorithms (Selection Sort, Insertion Sort, Bubble Sort) and Introduction to Advanced Sorting.

Topic Learning Outcomes:

Implement basic comparison-based sorting algorithms in C++.

Analyze and compare the time and space complexity ($O(n^2)$ vs $O(n \log n)$) of various sorting algorithms.

Determine the most suitable sorting algorithm for a given engineering problem domain.

🟢 FINAL PERIOD

Module VIII: Tree ADT

Topics: General Trees, Binary Search Trees (BST), AVL Trees, Tree Traversal Algorithms (Pre-order, In-order, Post-order, Level-order), Problem Solving using Trees.

Topic Learning Outcomes:

Define hierarchical data structures and tree-related terminology (root, height, depth, node).

Implement Binary Search Trees (BST) and demonstrate insertion, deletion, and search operations.

Execute tree traversal algorithms (DFS strategies and BFS/level-order).

Understand self-balancing trees (AVL trees) and the mechanics of rotations to maintain $O(\log n)$ operational complexity.

Module IX: Graph ADT

Topics: Graph Concepts; Adjacency Matrix and Adjacency List Representations; Breadth-First Search (BFS); Depth-First Search (DFS); Problem Solving using Graphs.

Topic Learning Outcomes:

Represent networks and systems using graph abstractions (directed/undirected, weighted/unweighted).

Implement graph data structures using Adjacency Matrices and Adjacency Lists in C++.

Implement graph traversal algorithms (BFS and DFS) to solve pathfinding and connectivity problems in engineering.

Module X: Comprehensive Algorithm Analysis

Topics: Theoretical and Experimental Methods in Measuring Time, Time Complexity Classes ($O(1)$, $O(\log n)$, $O(n)$, $O(n \log n)$, $O(n^2)$).

Topic Learning Outcomes:

Conduct real-system performance measurements and timing analyses on C++ implementations.

Compare theoretical Big-O complexity predictions against experimental bench-test results.

Synthesize optimal data structures and algorithmic designs to produce efficient software solutions.
